# Supplemental activities

In-class activities that go with the course modules but are not part of a module itself. Each notebook is self-contained and loads its data from a public URL, like the module notebooks.

| Notebook | Goes with | What it is |
|---|---|---|
| [A1_Why_Is_It_Blank](A1_Why_Is_It_Blank.ipynb) | [08.2 Missing Data](../08_data_cleaning/08_2_Missing_Data.ipynb) | Pair activity on the Fun Survey data: why are four columns blank for hundreds of rows, and what should you do about it? One partner writes short pandas snippets in the notebook (hints included); the other records answers. |
| [B3_When_Did_You_Answer](B3_When_Did_You_Answer.ipynb) | [08.7 Dates and Times](../08_data_cleaning/08_7_Dates_Times.ipynb) | Pair activity on the Fun Survey time stamps: what goes wrong when dates stay text (min, max, filters), when people answer, and how long a class or a break lasts. The code is given; one partner runs and edits it, the other records answers. |
